# Canonical licence texts

Verbatim texts used by `build-runtime.cjs` for packages of the bundled runtime that ship no licence file of their own
(their licence is declared in their `package.json`). Sources: `Apache-2.0.txt` from
https://www.apache.org/licenses/LICENSE-2.0.txt, `MIT.txt` from the SPDX license list
(https://github.com/spdx/license-list-data, `text/MIT.txt`). A package declaring a licence with no text here and
no file of its own makes the build fail.
