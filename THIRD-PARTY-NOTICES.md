# Third-party notices (Koda)

This file is the index of the third-party software Koda ships and where each one's licence text lives. The texts
travel with every installer.

| Component | Where it ships | Licence | Full notice and text |
| --- | --- | --- | --- |
| Gentle Dot (adapted code), Coucou (mechanics) | the daemon and the island | MIT | `apps/desktop-daemon/THIRD-PARTY-NOTICES.md` (installed as `desktop-daemon/THIRD-PARTY-NOTICES.md`) |
| sherpa-onnx 1.13.8 (speech to text, built without TTS on Linux and Windows: no espeak-ng or piper_phonemize) | statically linked into `abito-island` and `abito-transcribe` | Apache-2.0 | same file, «sherpa-onnx» |
| ONNX Runtime (inside sherpa-onnx's static libraries) | the same binaries | MIT | same file, «ONNX Runtime» |
| FFmpeg n9.0.2-49-gc179411bbb (revision `c179411bbb`), BtbN LGPL build (K2-13) | Linux and Windows: `runtime/ffmpeg[.exe]`; not shipped on macOS | LGPL-3.0-or-later | same file, «FFmpeg» (source location and offer); text in `runtime/LICENSE.ffmpeg.txt` |
| Node.js and Pi with every npm package they include (K2-02) | `runtime/` | MIT and others, per package | `runtime/THIRD-PARTY-NOTICES.md`, generated by `apps/desktop-tauri/packaging/runtime/build-runtime.cjs` |
| Rust crates compiled into the island binaries | `abito-island`, `abito-transcribe`, the Windows helpers | per crate (`apps/desktop-tauri/Cargo.lock`) | not generated yet |

Speech models (Parakeet, Whisper, Silero VAD) are not part of Koda. They are downloaded only when the user asks for
them, and each keeps its own licence, shown in Ajustes → Voz.

## FFmpeg: source offer and the mirror that is still missing (K2-13, S9)

Koda ships FFmpeg (LGPL-3.0-or-later) as a separate program, running it unmodified with command-line arguments only.
On request, the maintainers provide its Corresponding Source: the exact FFmpeg source at revision
`c179411bbb2864cc71323d3055acda25d5c2aace` — the commit FFmpeg's own version string labels
`n9.0.2-49-gc179411bbb`, a label and not the identity — together with the BtbN/FFmpeg-Builds scripts and the pinned
library versions linked into it, for at least three years after a release ships it, for no more than the cost of making
and sending the copy. That written offer is GPL-3.0 §6(b), incorporated by LGPL-3.0.

**Still missing before a public release:** Koda does not mirror those sources itself, and GPL-3.0 §6(d) — incorporated
by LGPL-3.0 with the rest of GPL-3.0 — requires recipients to be able to obtain the Corresponding Source from a
designated place (a network server or an equivalent), not only to ask us for a copy. The mirror must exist and be linked
from this file before the first public release. The licence review of FFmpeg (LGPL-3.0 obligations and the AAC/H.264
patent question) has **not** been done. This is an engineering record, not legal advice.
The detailed text travels with every installer: `apps/desktop-daemon/THIRD-PARTY-NOTICES.md` and the runtime's
generated `THIRD-PARTY-NOTICES.md` (`apps/desktop-tauri/packaging/runtime/build-runtime.cjs`).
